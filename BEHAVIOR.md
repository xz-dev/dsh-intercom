**Honesty notes:** DSH persists incoming user messages through its ordinary agent log, not Pi's custom `intercom_message` transcript entry with rich per-message details; the tool result carries text and presentation metadata, but Pi's dedicated overlay/history semantics are unavailable. Idle non-triggering policies use `agent.send(message, "next-step", false)` (`dsh-agent/lib/types/runtime-types.d.ts:175-186`) rather than `agent.steer`, which wakes an idle agent. Broker is local-only; peers need same `DSH_HOME`. Installation alone must not silently alter Pi's broker.
